## This is a fullstack assignment (Ruby on Rails + React)

You will build a scoped institutional staking portfolio experience: a Rails API that abstracts chain complexity, plus a React app for portfolio/rewards visibility and stake operation workflows.

## Start here

Switch to these branches in this same repository:

- `scratch`: Full requirements (build your own Rails + React apps)
- `boiler-plate`: Starter monorepo with Rails API + React stubs

```bash
git checkout scratch
# or
git checkout boiler-plate
```

If you still only see this PDF/README, you are on `main`. Switch branches to continue.
